# LuckyJ_Manager

## 一、简介

该项目旨在管理 LuckyJ 的牌谱何切集，实现储存、查找、复习等功能。

## 二、Manager

Manager 基于 Python Tkinter 实现。

### 1. 储存

Manger 可以储存牌谱何切。储存格式为 .json 文件。里面包括多项信息，在“新建”时由用户填入。

.json 文件内容：

```text
1. 序号（必填），对应 LuckyJ_NAGA_Reports.xlsx 文件中的序号。
2. 原牌谱链接（选填），对应的 LuckyJ 牌谱原天凤牌谱链接。
3. AI 复盘链接（必填），对应的主要 AI 复盘链接。
4. 参考 AI 复盘链接（选填），对应的次要/参考 AI 复盘链接。
5. 何切模式截图地址（选填），对应题目的何切模式截图的地址，这张图可以不存在。
6. AI 权重截图地址（必填），对应题目的主要 AI 权重截图的地址。
7. 参考 AI 权重截图地址（选填），对应题目的次要/参考 AI 权重截图的地址。
8. 标签（必填），给这道和何切题目打上多个标签，用于查找。
9. 文字解读（选填），用户自己输入的文字解读，复习时与 AI 权重截图一同出现。
10. 复习进度（Manager自动管理），用于复习。
```

文件储存结构：

```text
LuckyJ_Manager/
├── Files/                      # 储存 .json 文件及截图
│   ├── tag.txt                 # tag 仓库
│   ├── 1/                      # 牌谱1
│   │   ├── 1/                  # 何切2
│   │   │   ├── 1.json          # 何切2的 .json 文件
│   │   │   ├── 1_WhatCut.png   # 何切2的何切模式截图
│   │   │   └── 1_AI.png        # 何切2的AI权重截图
│   │   ├── 2/                  # 何切2
│   │   │   ├── 2.json          # 何切2的 .json 文件
│   │   │   ├── 2_WhatCut.png   # 何切2的何切模式截图
│   │   │   └── 2_AI.png        # 何切2的AI权重截图
│   │   └── ...                 # 牌谱1的多个何切
│   ├── 2/                      # 1,2,... 为牌谱序号
│   │   └── ...                 # 牌谱2的多个何切
│   └── ...                     # 多个牌谱
├── manager.exe                 # manager 可执行文件
├── Manager/                    # Python 文件夹
├── README.md                   # README 文件
├── WorkLog.md                  # AI 工作记录文件
└── ...
```

### 2. 查找

输入tag，查找符合tag的何切场景并展示。

### 3. 复习

根据复习进度，随机复习何切场景。

### 4. 界面

1. 初始界面：显示四个按钮，“新建”、“查找”、“复习”、“标签管理”。
2. 新建界面：先填牌谱信息（序号、原牌谱链接），再填何切信息（AI复盘链接、截图、标签、文字解读）；保存后保留牌谱信息，可连续添加同一牌谱的多道何切。图片选择截图路径后，Manager自动复制并统一转换为 .png 存到对应文件夹并重新命名。
3. 查找界面，根据输入，遍历所有.json文件，查找符合的何切场景并显示截图；可对选中的题目进行编辑或删除。
4. 复习界面，先展示需要复习的场景的何切模式截图（如果有的话，没有用AI权重截图）作为题目；点击“显示答案”后，在右侧出现 AI 权重截图与文字解读。显示三个按钮，“做对了”、“做错了”、“不再复习”。连续做对三次记录为不再复习，做错则重置。

### 5. 运行

环境要求：

```text
- Python 3.10+（开发环境为 3.13），需要 Tkinter（Windows 官方 Python 自带）。
- Pillow：用于把截图统一转换为 .png，以及图片的平滑缩放。
  未安装 Pillow 时程序仍可运行，但截图会保留原扩展名，图片缩放为整数倍、不够平滑。
```

安装依赖：

```bash
pip install Pillow
```

运行：

```bash
python Manager/main.py
```
