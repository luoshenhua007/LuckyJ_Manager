# LuckyJ_Manager

管理 LuckyJ 牌谱何切集的工具，提供 **储存、查找、复习** 功能，基于 Python Tkinter 实现。

## 快速开始

环境要求：**Python 3.10+**（需 Tkinter，Windows 官方 Python 自带）与 **Pillow**（用于截图统一转 `.png` 及图片平滑缩放）。

```bash
pip install Pillow
python Manager/main.py
```

首次运行会自动创建 `Files/` 数据目录。

## 功能说明

### 1. 储存

在「新建」界面录入何切题。每道何切保存为一个 `.json`，字段如下：

```text
1.  序号（必填），对应 LuckyJ_NAGA_Reports.xlsx 中的序号。
2.  原牌谱链接（选填），天凤牌谱原链接。
3.  AI 复盘链接（必填），主要复盘链接。
4.  参考 AI 复盘链接（选填）。
5.  何切模式截图（选填）。
6.  AI 权重截图（必填）。
7.  参考 AI 权重截图（选填）。
8.  主要标签（必填），影响何切选择的主要因素。
9.  次要标签（选填），辅助标签。
10. 文字解读（选填），复习时与 AI 权重图一同出现。
11. 复习进度（Manager 自动管理）。
```

文件存储结构：

```text
LuckyJ_Manager/
├── Files/                      # 数据目录（首次运行自动创建，不入 git）
│   ├── tags.json               # 标签仓库
│   ├── questions.json          # 疑问小局
│   ├── last.json               # 上次录入的序号与链接
│   ├── settings.json           # 用户偏好设置
│   ├── 1/                      # 牌谱序号
│   │   ├── 1/                  # 何切序号
│   │   │   ├── 1.json          # 何切信息
│   │   │   ├── 1_WhatCut.png   # 何切模式截图（选填）
│   │   │   ├── 1_AI.png        # AI 权重截图
│   │   │   └── 1_AI2.png       # 参考 AI 权重截图（选填）
│   │   └── ...
│   └── ...
├── Manager/                    # 源码
│   ├── main.py                 # 入口
│   ├── storage.py              # 数据层
│   ├── exporter.py             # 导出（长图 / PDF / ZIP）
│   └── ui.py                   # 界面
├── LuckyJ_NAGA_Reports.xlsx    # 牌谱序号对照表
└── README.md
```

### 2. 查找

输入标签查找何切。标签分**主要标签**与**次要标签**，三档匹配方式：

```text
1. 严格匹配：标签必须命中全部输入标签。
2. 尽量匹配主 tag：按主要标签命中数从多到少排序。
3. 尽量匹配 tag：按（主要+次要）标签命中数从多到少排序。
```

结果用「匹配」列显示命中数（命中数 / 输入标签总数）。标签匹配为**子串、忽略大小写**。

### 3. 复习

随机抽题，先展示何切模式截图（无则显示 AI 权重图），点「显示答案」后显示 AI 权重图与文字解读。连续做对 3 次记为「不再复习」，做错则重置。

### 4. 疑问

记录看不懂的小局（**不参与复习**），每条含：序号、小局（如 `e1.1`）、疑问点，以及自动带出的原牌谱 / AI 复盘链接。可在「疑问」界面查看、编辑，也可在新建何切时点「记录疑问…」随手记录。

### 5. 标签管理

标签存于 `Files/tags.json`，Manager 动态统计每个标签的使用次数，并按次数排序。支持**新增、重命名、删除（多选）、合并**（选中多个标签合并为一个，消除重复）。

### 6. 导出 / 导入

输入序号即可生成牌谱汇总：

- **长图 (PNG) / PDF**：顶部列出共用链接，随后为所有何切记录（图片 + 文字解读 + 标签）与所有疑问小局。
- **打包 (ZIP)**：把照片 + `manifest.json`（序号、标签、链接、解读、疑问等）无损压缩，用于**分享**。
- **导入 ZIP…**：选择他人分享的 zip，可**全选或勾选部分**何切与疑问，输入目标序号后自动收录（照片自动复制重命名，进度重置为 0）。

### 7. 设置

可设置**默认导出格式、默认导出目录、默认匹配方式**，存于 `Files/settings.json`。

## 界面一览

1. **初始界面**：功能按钮 +「设置」「退出程序」。
2. **新建界面**：左侧牌谱/何切信息，右侧「已有标签」（按使用次数排序，双击加到主要标签）；「保存并继续添加」会保留牌谱信息与主/参考 AI 链接，可连续录入；另有「恢复上次序号」「记录疑问…」按钮。
3. **查找界面**：按标签查找，预览区可滚动缩放；可编辑/删除题目。
4. **复习界面**：先题后答，含「做对了 / 做错了 / 不再复习」。
5. **疑问界面**：查看/编辑疑问，可打开对应链接。
6. **标签管理界面**：标签增删改与合并。
7. **导出/导入界面**：生成汇总或打包分享、导入 zip。
8. **设置界面**：默认导出格式、目录、匹配方式。
