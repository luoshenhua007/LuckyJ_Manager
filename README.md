# LuckyJ_Manager

## 一、简介

该项目旨在管理 LuckyJ 的牌谱何切集，实现储存、查找、复习等功能。

## 二、Manager

Manager 基于 Python Tkinter 实现。

### 1. 储存

Manger 可以储存牌谱何切。储存格式为 .json 文件。里面包括多项信息，在“新建”时由用户填入。

.json 文件内容：

```text
1. 序号（必填），对应 LuckyJ_NAGA_Reports.xlsx 文件中的序号。
2. 原牌谱链接（选填），对应的 LuckyJ 牌谱原天凤牌谱链接。
3. AI 复盘链接（必填），对应的主要 AI 复盘链接。
4. 参考 AI 复盘链接（选填），对应的次要/参考 AI 复盘链接。
5. 何切模式截图地址（选填），对应题目的何切模式截图的地址，这张图可以不存在。
6. AI 权重截图地址（必填），对应题目的主要 AI 权重截图的地址。
7. 参考 AI 权重截图地址（选填），对应题目的次要/参考 AI 权重截图的地址。
8. 主要标签（必填），影响何切选择的主要因素，多个标签用于查找，查找时优先匹配。
9. 次要标签（选填），次要/辅助标签，查找时作为补充匹配。
10. 文字解读（选填），用户自己输入的文字解读，复习时与 AI 权重截图一同出现。
11. 复习进度（Manager自动管理），用于复习。
```

文件储存结构：

```text
LuckyJ_Manager/
├── Files/                      # 储存 .json 文件及截图（首次运行自动创建）
│   ├── tags.json               # tag 仓库（首次运行自动创建）
│   ├── questions.json          # 疑问小局记录（首次运行自动创建）
│   ├── last.json               # 上次录入的牌谱序号与链接（首次运行自动创建）
│   ├── 1/                      # 牌谱1
│   │   ├── 1/                  # 何切1
│   │   │   ├── 1.json          # 何切1的 .json 文件
│   │   │   ├── 1_WhatCut.png   # 何切1的何切模式截图（选填）
│   │   │   ├── 1_AI.png        # 何切1的AI权重截图
│   │   │   └── 1_AI2.png       # 何切1的参考AI权重截图（选填）
│   │   ├── 2/                  # 何切2
│   │   │   └── ...
│   │   └── ...                 # 牌谱1的多个何切
│   ├── 2/                      # 2,... 为牌谱序号
│   │   └── ...
│   └── ...                     # 多个牌谱
├── Manager/                    # Python 源码
│   ├── main.py                 # 程序入口
│   ├── storage.py              # 数据层（json / 截图 / tag / 疑问 / 复习进度）
│   ├── exporter.py             # 牌谱导出（长图 / PDF）
│   └── ui.py                   # Tkinter 界面
├── LuckyJ_NAGA_Reports.xlsx    # 牌谱序号对照表
├── README.md                   # README 文件
├── .gitignore                  # git 忽略规则
└── manager.exe                 # manager 可执行文件（打包后生成）
```

### 2. 查找

输入 tag，查找符合 tag 的何切场景并展示。标签分为主要标签与次要标签，提供三档匹配方式：

```text
1. 严格匹配：结果的标签必须包含全部输入标签（主要+次要）。
2. 尽量匹配主 tag：按结果主要标签命中输入标签的数量从多到少排序。
3. 尽量匹配 tag：按结果标签（主要+次要）命中输入标签的数量从多到少排序。
```

结果列表用“匹配”列显示命中数量（命中数/输入标签总数）。标签匹配为子串、忽略大小写。

### 3. 复习

根据复习进度，随机复习何切场景。

### 4. 疑问

一局中可能有看不懂的小局，可以记录下来（不参与复习）。每条疑问记录包含：

```text
1. 序号（必填），对应 LuckyJ_NAGA_Reports.xlsx 文件中的序号。
2. 小局（必填），用户自己输入的小局标识，字符串类型（如“e1.1”）。
3. 疑问点（选填），类似文字解读的说明。
4. 原牌谱链接（选填），新增时自动写入（同序号牌谱）。
5. AI 复盘链接（选填），新增时自动写入。
6. 参考 AI 复盘链接（选填），新增时自动写入。
```

疑问统一保存在 `Files/questions.json` 中，主界面“疑问”按钮可查看、新增、修改、删除所有疑问（并有“打开原牌谱 / 打开AI链接 / 打开参考链接”按钮）；新增何切页面也提供“记录疑问…”按钮，新增时会自动带出当前牌谱的序号与原牌谱/主/参考 AI 复盘链接，方便录入何切时随手记录。

### 5. 标签管理

tag 仓库保存在 `Files/tags.json`。Manager 会动态统计每个标签被多少道何切使用（主要+次要标签合计），并按使用次数从多到少排序展示：

- 新建何切时，「已有标签」列表按使用次数排序，双击加到主要标签，也可选中后点“加到主要/加到次要”。
- 标签管理界面可新增、重命名、删除（支持多选）、以及合并标签：选中多个标签合并为一个，用于消除重复/相近的标签，避免混乱。

### 6. 导出牌谱

输入序号，选择格式，一键生成该牌谱的汇总文档（保存路径可自选）：

- 顶部：该牌谱共用的链接（原牌谱 / AI 复盘 / 参考 AI 复盘）只写一次。
- 内容：先是该序号下所有何切记录（按何切序号，图片 + 文字解读 + 标签），然后是所有疑问小局（小局 + 疑问点）。
- 格式：长图 (PNG) / PDF 二选一。

### 7. 界面

1. 初始界面：显示六个按钮，“新建”、“查找”、“复习”、“疑问”、“标签管理”、“导出牌谱”。
2. 新建界面：先填牌谱信息（序号、原牌谱链接），再填何切信息（AI复盘链接、截图、主要标签、次要标签、文字解读）；点“保存并继续添加”后保留牌谱信息和主/参考 AI 复盘链接（同一序号链接相同），只清空截图/标签/解读，可连续添加同一牌谱的多道何切。图片选择截图路径后，Manager自动复制并统一转换为 .png 存到对应文件夹并重新命名。「已有标签」按使用次数排序，双击加到主要标签。页面有“恢复上次序号”按钮（读 `Files/last.json`，一并回填原牌谱链接与主/参考 AI 复盘链接）和“记录疑问…”按钮（自动带出序号与链接）。
3. 查找界面，根据输入，遍历所有.json文件，按所选匹配方式（严格匹配 / 尽量匹配主tag / 尽量匹配tag）查找何切场景并显示截图；可用“何切图 / 主AI图 / 参考AI图”按钮直接切换查看，并可对选中的题目进行编辑或删除。
4. 复习界面，先展示需要复习的场景的何切模式截图（如果有的话，没有用AI权重截图）作为题目；点击“显示答案”后，在右侧出现 AI 权重截图与文字解读。显示三个按钮，“做对了”、“做错了”、“不再复习”。连续做对三次记录为不再复习，做错则重置。
5. 疑问界面：查看所有疑问小局，可新增、修改、删除，并可打开对应链接。
6. 标签管理界面：查看标签及使用次数，可新增、重命名、删除、合并标签。
7. 导出界面：输入序号并选择格式，生成牌谱汇总（长图 / PDF）。

### 8. 运行

环境要求：

```text
- Python 3.10+（开发环境为 3.13），需要 Tkinter。
- Pillow：用于把截图统一转换为 .png，以及图片的平滑缩放。
  未安装 Pillow 时程序仍可运行，但截图会保留原扩展名，图片缩放为整数倍、不够平滑。
```

安装依赖：

```bash
pip install Pillow
```

运行：

```bash
python Manager/main.py
```
